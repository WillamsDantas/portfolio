# Portfólio · Willams Dantas

Site de portfólio de Willams Dantas, designer e gestor de tráfego em Maceió.

- HTML, CSS e JavaScript puros, sem dependências.
- Fonte: Google Sans (Google Fonts, licença SIL OFL).
- Espaçamento e tipografia em grade de 4/8 pt (tokens no topo de `assets/css/style.css`).
- Paleta: grafite com gradiente dourado nos botões.
- Publicado pelo GitHub Pages.

## Editar

- Textos: `index.html`
- Cores, tamanhos e espaçamentos: variáveis em `:root` no `assets/css/style.css`
- Imagens: `assets/img` (WebP)
- Interações (menu, trilhos, abas, tela cheia): `assets/js/main.js`

Para ver localmente, abra a pasta e rode `python3 -m http.server`, depois acesse `http://localhost:8000`.
